# FRSBIM4d — Four Seasons Residences

เว็บ BIM 4D ภาษาไทยพร้อม HUD ลอยตัว โทน Clean Mint สำหรับตรวจโมเดล R01 จาก DWG

**เว็บไซต์:** https://netzpj-max.github.io/FRSBIM4d/

- 14,642 ชิ้นส่วน / 73 ระดับที่สร้าง / 280 กิจกรรมสมมติ
- หมุน ซูม เลือก กรอง ซ่อน/แยกดูชิ้นส่วน และเปิดภาพเส้นแบบอ้างอิง
- แผนเวลาเริ่ม 2015-05-15 แก้ไขและส่งออก JSON/CSV ได้
- ราคาและข้อมูลที่แก้บันทึกเฉพาะเบราว์เซอร์ของผู้ใช้ สำรอง/นำกลับเข้าได้ ไม่มีฐานข้อมูลกลาง
- ภาพเส้น 63 ไฟล์และทะเบียน DWG 728 ไฟล์ ไม่รวม DWG ต้นฉบับหรือ ZIP ส่งมอบ
- โมเดล IFC2x3 อยู่ใน `model/` และแผน 4D อยู่ใน `data/schedule.json` / `data/schedule.csv`

## ขอบเขต

โมเดลเพื่อพิจารณาที่มีค่าประมาณ ไม่ใช่ Full BIM หรือแบบก่อสร้างรับรอง แผนเวลาเป็นสมมติฐานและไม่มีข้อมูลความคืบหน้าจริง ระดับอาคารบางจุดยังขัดกัน ฐานราก คาน งานระบบ ขั้นบันได ราว และช่องเปิดยังไม่ครบ การเปิดจริงใน Archicad 26 ยังไม่ยืนยัน และไม่มี PLN

## แก้เว็บต่อ

ไฟล์ต้นฉบับอยู่ที่ root: `index.html`, `app.js`, `style.css`, `theme-clean.css`, `hud.css` และ Three.js ใน `vendor/` ไม่ต้อง build ใช้ static server เช่น `python -m http.server 8766` แล้วเปิด http://127.0.0.1:8766/ (ไม่ควรเปิด HTML ด้วย file://)

เส้นทางข้อมูลใช้ relative URL จึงทำงานภายใต้ `/FRSBIM4d/` ได้ GitHub Pages เผยแพร่จาก `main` / root และ `.nojekyll` รักษาการเสิร์ฟ static files

## ข้อมูลและรหัส

`data/elements.json` เชื่อม `id`, `ifcGuid`, `sourceId`, `activityId` กับ IFC ทะเบียนแบบ และแผนเวลา รักษารหัสเดิมเมื่อแก้ข้อมูลต่อ `data/elements.csv` และ `schedule.csv` เปิดแก้ด้วยโปรแกรมตารางได้ ปริมาณเป็น gross geometry ตามขอบเขตที่รายงาน ไม่ใช่ BOQ จัดซื้อ

อ่านผลตรวจใน `reports/verification.json`, `reports/ui-hud-qa.json` และขอบเขตข้อมูลใน `data/project.json` ผล QA เดิมเป็นผลตรวจในเครื่องก่อนเผยแพร่ ผลตรวจเว็บสาธารณะบันทึกแยกใน public-deployment.json เมื่อยืนยันการเผยแพร่

## การใช้ต่อ

การเปิดสาธารณะไม่ได้เพิ่มสิทธิ์ในแบบก่อสร้างหรือเนื้อหาอ้างอิง เคารพสิทธิ์ของเจ้าของเนื้อหาเดิม Three.js ใช้ตามใบอนุญาตใน `vendor/`
